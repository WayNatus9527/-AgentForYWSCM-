# M6 复盘与 Agent 设计

承接 v0.9.0 / 迁移 8；迁移 9 追加分析任务、不可变报告及证据行、改善任务关联和工具审计。以下为实施约定，交付结果以最终验收摘要为准。

- 仅读取授权业务数据库与不可变事件，不读取模拟器私有事实。事件实际、接收、登记时间分开；模拟运行的默认业务事件登记使用虚拟业务时钟，认证和租约仍使用真实时间。旧数据不补造实际时间。
- 事件时间订正追加引用链，原事件和旧报告保持不变；并发订正按最新证据版本检查，负时长或时钟异常保持未知并可生成质量核实任务。
- 按到货、检验批次、履约批次和审批单形成明确粒度的指标；自然时长与版本化工作日历时长并列。已完成分位数与未完成在制、当前等待分开，样本数及未知分母可见。
- 采购原始/最新承诺到货表现分别统计，最新承诺以该次签收前已登记承诺为准。库存可用、实物交接和渠道完成不可混为一个节点。
- 订单影响仅来自显式供给关联和实际履约任务。重建预占、取消、交接及关联释放时序，已获得其他现货的数量不继续当作缺货阻塞。并行区间取并集、同一订单行数量按时间去重，不累计为总损失。
- 先展示等待超出所选预算、到达/处理速率、持续积压及承诺偏差，再检查实际依赖。正常长运输只属耗时较长；可信实际到达且补录迟到属于数据延迟；无证据保持原因未知。排序明确采用影响订单、超期和在制数量，不输出概率分数。
- 分析任务持久化并由后台执行，可恢复租约。报告、明细分页及单笔时间线可追溯，历史报告读取重新检查仓库和连接权限。改善任务按报告候选去重，不能绕过原审批与库存流程。
- Agent 工具仅执行授权的解释、跟踪、规则计算和待确认方案。模型只选择严格契约，未知 ID、歧义和越权均不能猜测；规则入口无密钥可用，真实模型验收单列。
- 固定金标准覆盖质检等待、正常长运输、补录延迟、未知时间、并行依赖和混合限制；独立随机预期由模拟器持有并比较误报、漏检、影响量误差及未知率。成对实验仅改变一个能力参数，按种子比较端到端结果及限制迁移。
