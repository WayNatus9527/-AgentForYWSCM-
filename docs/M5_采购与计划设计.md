# M5 采购与计划设计

承接 v0.8.0 / 迁移 7，仅使用模拟数据。此文描述实施约定，最终结果以本阶段验收摘要为准。

- 迁移 8 只追加采购条款、统一供给行、运输批次、到货凭证、检验关联、差异审批、动作历史、需求日记录、补货策略、计算快照和确认记录。既有采购/调拨单与行继续作为业务主单。
- 新采购保存真实供应商资料 ID、下单时间、原始与最新承诺；承诺变更追加原因和事件。采购批次记录计划发出/到达、实际发出/到达；采购实收按到货历史累计，退供应商不重置实收。待验通过明确凭证关联检验，不能挪用或伪造已经上架。
- 补发新采购显式关联已执行供应商退货，验证同供应商、仓库、商品和累计实退上限。原采购、退货、补发均保持独立历史，关闭补发不自动释放历史关联上限。
- 新调拨由计划行分批预占，每批独立运输信息；发出全批预占量，按批可分次签收。取消批次释放未发预占，计划余量可关闭。损失由另一管理员按批审批，部分批次差异不关闭其他在途。
- 新管理单据拒绝旧整体收发/差异接口旁路；旧未迁入单据保留原流程。所有实物与承诺变化仍经统一入账，盘点锁及质量保护继续执行。
- 供给视图按唯一供给行与批次拆成未分批计划、未发批次、在途。入库即退出未来供给；过期、时间未知、未预占调拨单列风险，不计入可信及时供给。
- 需求历史逐日保存来源凭证和质量状态；缺日、冷启动或异常保持未知，明确的零需求允许。预测采用窗口均值乘提前期加覆盖天数，整数向上取整。
- 策略明确预测是否已含未履约订单。已含时，目标需求取预测与已知未履约量较大者，再减同范围已预占量；未含时，预测加未预占订单量。库存使用扣除各承诺后的未分配库存，从需求同步排除已经扣库存的订单预占，避免重复净减。渠道额度继续保留，不能假设可挪用。
- 净补量为未覆盖需求加目标安全量，减未分配现货及可信及时供给，下限为零；非零结果按最小采购量及包装倍数调整。安全量是计划目标，不改物理保留 B。
- 每份方案保存输入、版本、明细、未知原因和建议。人工确认前复查创建者、权限、库存、策略、需求与供给版本；修改数量和理由追加保存，确认与生成采购单同事务。无模型密钥可完成全部操作。
- 验证覆盖 FR05、FR07、FR22 / AT02、AT04、AT13，另回归权限、幂等、盘点锁、隔离与恢复。开发数据不计入额外验收；两数据库各运行新独立种子，M6 诊断与容量不在本阶段结论中。
