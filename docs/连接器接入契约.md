# 连接器接入契约

v0.8.0 已实现本地模拟适配器；当前无真实接入。真实服务仍须逐项确认以下契约并独立验收。

| 项目 | 必填内容 |
|---|---|
| 身份 | 服务商、账号、商户、仓/店/站点、API版本、权限范围 |
| 数据职责 | 库存实物/订单承诺/履约/退款的权威来源及字段包含关系 |
| 事件 | event_id、business_action_id、entity_id、entity_version、occurred_at、received_at、payload |
| 快照 | snapshot_id、covered_watermark、snapshot_at、库存状态及原始字段；无水位显式null |
| 查询 | 按我方业务编号查询外部建单/取消/出库状态；区分不存在、处理中、成功、失败、未知 |
| 回写 | 比较数量/版本条件、幂等键、绝对值权威限制、SKU/仓串行顺序 |
| 限流 | 配额、分页稳定性、重试等待提示、授权过期处理 |
| 安全 | 验签、敏感字段最小化、凭据服务端保存、日志脱敏 |
| 异常 | 联系人、服务时段、撤回未确认处理、人工接管格式 |

事件去重边界由运行空间、商户、连接账号及源事件编号组成，业务动作另设唯一关联，不以名称或收到消息的时间代替源标识。库存余额仅通过领域事务修改，适配器不得直接写余额表。

API返回200不等于库存撤回或取消已完成，必须得到业务确认。无可靠水位不允许自行推断快照已覆盖哪些出库；无查询能力的超时建单禁止盲目重建。外部能力不足时保留未知状态并停止新增不可信承诺。

真实验收需订单、取消竞争、实际出库、退货、库存回写、重复/迟到回执、快照对账及未知结果查询八类证据。模拟适配器只证明内部接口可调用，不能把连接状态设置为正常。

## M4 已实现的模拟契约

`app.delivery.ConnectorAdapter` 提供 `execute`、按原业务编号的 `query`、实体原事件 `query_event` 和 `query_snapshot`。模拟执行结果区分 `not_found`、`processing`、`succeeded`、`failed`、`unknown`，限流和断连另有可重试结果。模拟效果独立事务持久化，以便验证外部已成功而本地尚未确认的崩溃边界。

事件模型采用 `source_event_id`、`business_action_id`、`entity_id`、可空 `source_version`、可空 `occurred_at`、`run_id`、`tenant_id`、`kind` 和 `payload`；连接账号由受授权的路由指定，`received_at` 由系统登记。支持 `order.created`、`order.cancelled`、`order.completed`、`shipment.delivered`、`stock.delta`。订单与运输实体版本分开，库存增量使用自身序号；不将实物发出与渠道完成合并。

快照保存 `snapshot_id`、仓库、商品、`snapshot_at`、`covered_watermark` 和良/待/残数量。缺可靠水位时对账保持未知，不叠加全部历史增量。比较输入和结果追加保存。

模拟来源原始事件须显式注册，不能用当前本地订单状态冒充来源事实。支持查询和幂等能力由连接配置声明；缺少任一必要能力时，超时动作进入人工接管。当前模拟连接只配置自营仓范围，真实海外仓或供应商特有字段映射需后续适配器完成。

接口及限制见 [M4 交付说明](M4_履约与协同交付说明.md) 和 [OpenAPI](openapi.json)；本地模拟通过不代表真实连接连通或服务能力已通过验证。
